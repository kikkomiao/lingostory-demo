# LingoStory 宣传页首屏概念稿

- `concept-a-interactive-comic.jpeg`：互动漫画现场，功能表达最直接。
- `concept-b-eight-second-mission.jpeg`：八秒沟通任务，视觉冲击最强。

这些图片用于方向选择，不是最终视觉资产。选定后需使用现有 NPC 素材锁定角色一致性，并继续制作各个独立页面区块。

## 第二轮：手绘扁平生活漫画

- `concept-v2-a-living-task.jpeg`：任务现场，最接近可直接落地的产品首屏。
- `concept-v2-b-story-branch.jpeg`：一句话改变剧情，最准确表达产品核心创新。
- `concept-v2-c-everyday-world.jpeg`：生活任务宇宙，最适合表现多 NPC 与多场景扩展性。

第二轮统一使用非写实人物系统：粗黑手绘线、圆润敦实比例、极简五官、放大的手脚、明快纯色色块与轻微纸张颗粒。
