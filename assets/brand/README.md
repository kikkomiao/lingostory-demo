# LingoStory Logo

项目后续统一使用这里的 `LingoStory` 字标，不再使用自动生成的替代字标或图标组合。

- `lingostory-wordmark-white.png`：标准白色透明底版本，用于蓝色、红色、黑色和图片深色区域。
- `lingostory-wordmark-ink.png`：同字形深墨色版本，用于奶油白或浅色背景。

使用约束：

- 保持原始宽高比，不拉伸或压缩。
- 不重新排字，不替换字体，不改变字母间距。
- `g` 中的三个圆点属于 Logo，必须保留。
- 可以整体更换为单一纯色，但不要使用渐变、描边或发光效果。
- 四周至少保留约一个小写字母笔画宽度的安全空间。
